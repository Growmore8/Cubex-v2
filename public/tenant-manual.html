Platform Overview
Understanding the trading platform structure

Your white-label trading platform is a fully managed, multi-tenant system. As a tenant (broker), you get a dedicated environment where you control your clients, managers, groups, spreads, and trading conditions — completely isolated from other brokers on the same infrastructure.

Platform Structure

Level 1
Super Admin (OrbitFxSolution)
Manages all tenants, platform-wide symbols, billing, and global settings. You do not have access to this level.
Level 2
Admin (You — the Broker/Tenant)
Full control over your tenant: create clients, managers, groups, set spreads, leverage, symbol access, and all trading conditions.
Level 3
Manager
Handles a subset of clients assigned to them. Can perform actions (deposits, trades, etc.) based on permissions you grant.
Level 4
Client (Trader)
End users who trade on the platform. They see their own accounts, balances, positions, and history only.
💡
Key concept

Everything you configure as Admin applies only to your own clients. Other tenants on the platform are completely isolated — they cannot see your clients or settings, and you cannot see theirs.

Spread System
3-level spread hierarchy — how the final spread is calculated

The platform uses a 3-level spread hierarchy. Each level adds a markup on top of the previous one. The final spread a client sees is the sum of all three levels.

Layer 1 — Admin sets
Symbol Spread (Base)
Set in Market Watch → right-click category header. This is the raw spread for each trading symbol (e.g. EURUSD = 1.0 pip base). Applies to all clients in the tenant.
Layer 2 — Admin sets
Group Spread Markup
Added on top of Layer 1. Set via group right-click → Spread Settings. Applies to all members of that group. Can be Fixed or Floating.
Layer 3 — Admin or Manager sets
Account Spread Markup
Added on top of Layer 2. Set via client right-click → Settings → Spread Markup. Applies to this single account only. Can be Fixed or Floating.

Formula

Final Spread = Symbol Base + Group Markup + Account Markup

Example

Symbol base (EURUSD)1.0 pip1.0 pip
Group markup (VIP Group)+ 0.5 pip1.5 pips
Account markup (Client A)+ 0.3 pip1.8 pips total

TypeBehaviourWhen to use

Floating Markup varies between a Min (market hours) and Max (off-hours / low liquidity) value Retail clients, volatile or off-hours protection

Symbol Access Control
Enable or disable trading symbols at group or account level

Symbol Access lets you control which trading symbols each group or individual client can trade. A disabled symbol will not appear in the client's Market Watch and cannot be traded.

3-Level Symbol Priority

LevelWho controlsScopeOverrides
Tenant (platform)Super AdminAll clients in the entire tenantOverrides everything below
GroupAdminAll members of that groupOverrides account setting
AccountAdmin or ManagerSingle account onlyOnly takes effect if group allows it
⚠️
Disable at higher level = blocked everywhere

If a symbol is disabled at the Tenant level, no client can trade it regardless of group or account settings. If disabled at Group level, all members are blocked even if the account-level says enabled.

How to Set Group Symbol Access

1
Right-click the Group

In the Navigator, right-click the group header.

2
Click "Symbol Access"

The Symbol Access panel opens — it shows the group name in the header so you know which group you are editing.

3
Toggle Symbols On/Off

Search or scroll to find symbols. Toggle the switch to disable or enable each symbol for all group members.

4
Save

Changes apply immediately to all clients in the group.

Margin Call Level

The Margin Call Level is a percentage at which the system automatically triggers a margin call warning or position close. It is set as a percentage of the required margin.

ValueMeaning
0%Margin call disabled — positions will never be auto-closed by margin
50%Margin call triggers when equity drops to 50% of required margin (default)
100%Margin call triggers when equity equals required margin (aggressive)

Set Margin Call for a Group (bulk)

1
Right-click the group → Group Margin Call

The flyout opens with a number input.

2
Enter the percentage

Type a value between 0 and 500. Set to 0 to disable.

3
Click "Apply to all members"

All clients in the group are updated.

ℹ️
Per-account overrides always win

If you apply a group leverage/margin call then individually change one client, the individual setting takes effect for that client. Future group-level applies will overwrite it again.

Permissions Reference
Complete permissions matrix for admins and managers

How Permissions Work

There are two layers of permissions that must both be enabled for any action to work:

Layer 1
Tenant Permissions (set by Super Admin)
Master gates for the entire tenant. If a permission is OFF here, no one in the tenant can use it — regardless of manager settings. Example: if "editSpread" is off at tenant level, no admin or manager can edit spread.
Layer 2
Manager Personal Permissions (set by Admin)
Individual manager permissions within the tenant. Even if tenant-level allows a permission, the manager only gets it if Admin specifically grants it to them.
